Robot observation

Smooth grasp

A+MLP with the direct joint head produced a smooth pick-and-place trajectory and successful grasp behavior in repeated on-robot trials. A formal success rate is still pending.

What the offline metrics say

MLP reduced the 30-step TCP position error and internal chunk displacement by roughly half to four-fifths versus FM. Adding Aria data did not improve this in-domain Piper split.
